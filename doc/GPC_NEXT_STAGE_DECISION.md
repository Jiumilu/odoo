## 2. 下一阶段计划

### 最大阻塞

- 外部集成沙箱连通证据。

- GPC-P0-002：核心业务流程闭环已完成。
- GPC-P0-003：部署、运维、回滚说明已补齐。

## 3. 三类专项行动

### 专项一：运行健康专项

目标：保留项目能稳定安装、启动、运行，有明确启动说明和环境变量。

GlobalCloud GPC 当前状态：运行健康已达标，但启动说明和环境文档未达标。

交付物：

- 中文 README。
- 部署说明。
- 运维说明。
- 健康检查命令固化到 CI。

### 专项二：核心功能闭环专项

目标：至少验证 3-5 条核心业务流程，消灭假按钮、mock 残留、断点流程。

GlobalCloud GPC 第一轮最小流程建议：

1. 用户登录 -> 后台首页 -> 应用导航。
2. Website 首页访问 -> 联系入口 -> 表单或联系方式验证。
3. Discuss 打开 -> 频道查看 -> 消息发送或只读权限边界验证。
4. 核心业务模块安装候选流程：销售/采购/库存任选一条，先确认能否安装，再做 create/read/update smoke。

### 专项三：测试证明力专项

目标：为核心流程补最小可用自动化测试或可复现 smoke test。

第一轮要求：

- CI 跑最小 Odoo test runner。
- 健康脚本成为固定 smoke test。
- 中文化 PO 检查成为固定质量门禁。
- 每条核心流程至少有可复现命令或手工验收步骤。
