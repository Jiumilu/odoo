# GlobalCloud GPC 中文术语表

日期：2026-06-06

## 1. 品牌与系统名称

| 英文/代码名 | 中文名称 | 使用规则 |
|---|---|---|
| GlobalCloud GPC | 绿色供应链公共服务平台 | 面向用户的系统全称优先使用中文，品牌或技术上下文可保留 `GlobalCloud GPC` |
| GPC | 绿色供应链公共服务平台 | 文档短称可写 `GPC`，首次出现应给出中文全称 |
| Odoo | Odoo | 仅在说明上游框架、许可证、开发参考时保留；用户界面和交付文案不得以 Odoo 作为系统品牌 |

## 2. 核心业务模块

| 上游模块/英文 | GPC 中文术语 | 说明 |
|---|---|---|
| Contacts | 联系人 | 客户、供应商和往来单位基础资料 |
| CRM | CRM | 行业通用缩写，中文界面可保留 |
| Sales | 销售 | 销售订单、报价和客户交易流程 |
| Purchase | 采购 | 采购订单、供应商交易流程 |
| Inventory | 库存 | 收货、发货、库存数量和库存移动 |
| Manufacturing | 制造 | 制造工单、物料清单和生产状态 |
| Project | 项目 | 项目和任务管理 |

## 3. 测试与交付术语

| 术语 | 建议中文 | 使用规则 |
|---|---|---|
| Smoke test | Smoke 测试 / 冒烟测试 | 技术文档可保留 `smoke`；面向管理报告写“冒烟测试” |
| E2E | E2E / 端到端测试 | 技术文档可保留 `E2E`，首次出现补充中文 |
| CI | CI / 持续集成 | 技术和交付文档可保留 `CI` |
| Coverage | 覆盖率 | 报告中写“覆盖率”，命令或工具名保持英文 |
| Rollback | 回滚 | 运维、上线文档统一用“回滚” |
| Release notes | 发布说明 | 交付物名称统一为“发布说明” |
| Changelog | 变更记录 | 交付物名称统一为“变更记录” |

## 4. 权限与异常

| 英文/技术词 | 中文文案 | 使用规则 |
|---|---|---|
| AccessError | 权限不足 | 用户提示使用中文，技术日志可保留异常类名 |
| Session expired | 会话已过期 | 用户提示应说明需要重新登录 |
| Page Not Found | 页面未找到 | 404 页面标题和正文统一使用中文 |
| Server Error | 系统错误 | 用户提示不得暴露 traceback |

## 5. 保留英文的技术词

以下词在中文文档和界面中可保留英文，以避免行业歧义：

- API
- CRM
- CI
- E2E
- JSON
- OAuth
- PostgreSQL
- Playwright
- WebSocket

## 6. 禁止混用

- 不得在用户可见主路径中把系统称为 `Odoo`。
- 不得继续使用 `YourCompany`、`OdooBot`、`Powered by Odoo` 表示当前系统品牌。
- 不得把 `GlobalCloud GPC` 翻译成多个不同中文名称。
