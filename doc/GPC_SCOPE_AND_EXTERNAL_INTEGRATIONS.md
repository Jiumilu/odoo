# GlobalCloud GPC 范围与外部集成说明

日期：2026-06-06

## 1. 当前评分范围

当前 100 分目标只允许基于已启用、已配置、可复跑验证的系统范围评分。

已纳入范围：

- Odoo 本地运行健康。
- 中文品牌和中文用户主路径。
- 联系人、CRM、销售、采购、库存、制造、项目。
- 公开网站、登录页、404 页。
- 关键 JSON 错误提示。
- 权限边界 smoke。
- CI、测试报告、覆盖率基线、部署/运维/回滚文档。

未纳入当前交付范围：

- 真实邮件发送。
- 真实短信发送。
- Outlook/Gmail OAuth 联通。
- Recaptcha 生产密钥。
- 在线支付生产通道。

## 2. 外部集成治理原则

未配置凭证的外部集成不得被计入“已完成集成”。它们只能计为：

- 已安装模块。
- 已识别外部依赖。
- 已列入后续联调范围。
- 当前核心流程不依赖。

## 3. 当前验证结论

当前核心业务 smoke 不依赖邮件、短信、OAuth、Recaptcha 或支付生产通道，因此这些外部集成不阻塞当前“本地可开发、可验证、接近交付准备”的评分。

若要把“可上线”也评为 100，必须补充真实或沙箱凭证并完成连通测试。
